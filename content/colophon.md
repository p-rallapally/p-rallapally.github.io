A colophon is a statement at the end or beginning of a book detailing its production. The concept of the colophon for this website, as well as many other stylistic and formatting decisions, were blatantly stolen from fellow UCSB alum [Tanay Biradar](https://tanaybiradar.com/).

This website is written with [Zola](https://www.getzola.org), a static site generator. The color scheme is [Flexoki](https://stephango.com/flexoki) by Steph Ango. The font is [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans), hosted on this domain. I host on [GitHub Pages](https://pages.github.com/), and the source code is [open-source](https://github.com/p-rallapally/p-rallapally.github.io).
